# VIP 视频智能搜索

Chrome/Edge 浏览器扩展 — 输入电视剧/动漫名称，自动搜索全网可播放资源，一键播放。

## 功能

- 输入名称自动并发搜索多个影视资源站（CMS 聚合 API）
- 智能合并去重来自不同源的搜索结果
- 35 个内置解析接口，popup 打开时自动预热检测可用性
- 自动选择最快可用的解析接口，搜索零等待
- 点击剧集直接在新 tab 播放

## 安装

1. 下载/克隆本项目
2. 打开 `chrome://extensions/`（或 `edge://extensions/`）
3. 开启"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择 `vip-search-extension` 目录

## 使用

1. 点击浏览器工具栏中的扩展图标
2. 等待顶部状态显示"✓ X 个接口可用"（通常 2-3 秒）
3. 输入想看的电视剧/动漫名称
4. 点击搜索，等待结果
5. 点击任意剧集按钮即可在新标签页播放

## 技术架构

```
popup (搜索UI) ←→ service-worker (后台) ←→ CMS API + 解析接口
```

- **Manifest V3** Chrome 扩展
- **原生 JS / HTML / CSS**，无框架依赖
- **CMS 采集站 API**：标准 `/api.php/provide/vod/` 格式
- **解析接口预热**：popup 打开时全量并发检测 35 个接口
